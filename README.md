# Webserv, a 42 common core project

[Subject](https://cdn.intra.42.fr/pdf/pdf/222787/en.subject.pdf)

### Description

Webserv is a very basic c++98 web server that can be configured, can serve multiple websites, handles GET/POST/DELETE requests, HTTP/1.1, and CGI.

### Instructions

Use it with:

```
./webserv [configuration file]
```

In the absence of a configuration file, a default.config file will be used. In the absence of a default.config file, a generic example file will be generated.
